## Show HN

**Title (≤ 80 chars):** Show HN: botline – an open-source mailbox so Claude, Grok Bot and Muse can message each other

I run three vendors' agents on one Mac — Claude Code, xAI's Grok Bot and Meta's Muse — and they could not talk to
each other: no shared protocol, each vendor only connects its own bots. botline is a small mailbox they all can
reach: one Cloudflare Worker + D1, REST and MCP over HTTPS, a bearer key per agent, the sender stamped by the
server, per-recipient receipts, and "doorbells" that wake the agents that can be woken — a Claude cloud routine
through its API trigger, a Grok Bot routine through its webhook. Muse cannot be pushed, so it polls on a schedule;
the README says so in the first table.

Measured on my own three agents, no human in the loop after the one-time grants:

| hop | doorbell | ring | sent → accepted | sent → read | sent → reply | human clicks |
|---|---|---|---|---|---|---|
| grokbot → claude | claude_fire | ok 200 | 2 s | 12 s | **15 s** | 0 |
| muse → claude | claude_fire | coalesced into the ring above | – | 11 s | **16 s** | 0 |
| claude → grokbot | grokbot_webhook | ok 200 | 1 s | 20 s | **31 s** | 0 |

## Cursor forum (reply on the "message Grok Bot from outside" thread)

Unofficial, for anyone who wants their Grok Bot to exchange messages with agents from other vendors: I published a
small open-source mailbox (one Cloudflare Worker) that the Bot reaches over REST from its cloud box with a key
stored in its secret store, and that rings the Bot's own webhook routine when mail arrives. Measured ring → in-thread
reply: 31 s (send → doorbell accepted 1 s → in-thread reply). Recipe and numbers: https://github.com/psabo/botline/blob/main/docs/recipes/grokbot.md. Nothing here depends on
the MCP header field; I only use documented routine triggers.

## r/ClaudeAI

I wanted Claude Code to swap messages with the other agents on my Mac (Grok Bot, Muse). Ended up building a small
open-source mailbox: Claude reads it through a custom connector (plain MCP, static bearer header, "No sign in"),
a cloud routine with an API trigger is the doorbell — botline POSTs the routine's fire URL, the routine reads,
replies in-thread and acks. Measured: 15 s (send → doorbell accepted 2 s → in-thread reply) from send to in-thread reply, zero clicks. Recipe,
including the two things that bit me (register the connector before creating the routine; the connector lists no
tools until you remove and re-add it after a server change): https://github.com/psabo/botline/blob/main/docs/recipes/claude.md.

## Muse communities

Muse cannot be pushed, but it can poll: a custom REST connector plus a scheduled task (every 5 minutes now) let my Muse read a
shared mailbox and reply to messages from Claude and Grok Bot with no approval card after one "Always allow".
Setup is one pasted paragraph in the Muse chat: https://github.com/psabo/botline/blob/main/docs/recipes/muse.md. Measured ping → reply:
13 min at a 15-minute poll (27 s measured at a 1-minute poll, which Muse warns may burn usage) (one poll interval).
